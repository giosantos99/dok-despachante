# 🚗 Landing Page - DOK Despachante

Este projeto é uma landing page responsiva desenvolvida como desafio técnico para a **DOK Despachante**. A aplicação apresenta informações sobre o programa de afiliados, formulário de cadastro dinâmico e elementos visuais otimizados.
---

![Preview da Landing Page](./preview/preview-dok.png)

---

## 🧪 Tecnologias Utilizadas

* **HTML / Template Engine:** Pug (`vite-plugin-pug`)
* **Estilização:** Sass (Arquitetura 7-1), Bootstrap 5
* **Linguagem / Scripts:** JavaScript (ES6+)
* **Build Tool:** Vite
* **Ícones:** Bootstrap Icons & Custom Inline SVGs

---

## ⚡ Funcionalidades e Destaques

* **Design Responsivo:** Adaptado para dispositivos móveis, tablets e desktops.
* **Validação de Formulário:** Validação dinâmica de campos (nome e e-mail) com tratamento de erros em tempo real e alerta visual.
* **Componentização UI:** Cards de motivos de afiliados com alturas equivalentes, ícones vetorizados e efeitos de hover (`translateY`).
* **Arquitetura Modular:** Separação da lógica de validação de scripts (`formAfiliado.js`) e módulos Sass.

---

## 🚀 Como Rodar o Projeto Localmente

### Pré-requisitos
Antes de começar, certifique-se de ter o **Node.js** e o **npm** instalados em sua máquina.

### Passo a Passo

1. **Clone o repositório:**
   ```bash
   git clone [https://github.com/giosantos99/DokDespachante.git](https://github.com/giosantos99/DokDespachante.git)
   ```

2. Instale as dependências:

npm install

3. Execute o servidor de desenvolvimento:

npm run dev

4. Acesse no navegador:

O terminal exibirá o link do servidor local (geralmente http://localhost:5173/).

---

## 🛠️ Comandos Disponíveis

* npm run dev: Inicia o servidor local com Hot Module Replacement (HMR).
* npm run build: Gera os arquivos finais otimizados para produção na pasta dist/.
* npm run preview: Visualiza o build de produção localmente.
